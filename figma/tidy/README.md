# Fold Supply · Tidy layout

A one-click fix for a Fold Supply Figma file made by the first version of the design-file plugin. It fixes boards that overlap, text spilling out of rows, and squashed component holders.

1. Open the Fold Supply file in the Figma desktop app, with Chillax installed.
2. Open the menu, then **Plugins → Development → Import plugin from manifest…**, and pick `manifest.json` in this folder.
3. Open the menu, then **Plugins → Development → Fold Supply · Tidy layout**.
4. Wait for "Tidy done: 10 pages". Running it again does no harm.

It makes every frame grow to fit its content and lets text wrap downwards. It puts the component variants in neat rows and spaces the boards on each page 160 px apart. Buttons, the desk-edge band and the closed mobile tab keep their fixed heights.
